# Delphi-RPG 🎮

Proyecto personal de aprendizaje y desarrollo de un RPG utilizando **Delphi / Object Pascal**.

La idea de este proyecto es aprender progresivamente a desarrollar un videojuego desde cero, aplicando conceptos de programación orientada a objetos y creando diferentes sistemas propios de un RPG.

> 🚧 **Estado del proyecto:** En desarrollo

## 🎯 Objetivos

* Aprender y mejorar mis conocimientos de Delphi y Object Pascal.
* Aprender programación orientada a objetos mediante un proyecto práctico.
* Crear un RPG con identidad y mecánicas propias.
* Desarrollar progresivamente sistemas de personajes, enemigos, combate, habilidades, objetos y otras mecánicas.
* Documentar la evolución del proyecto mediante Git y GitHub.

## 🧩 Actualmente

El proyecto se encuentra en una etapa inicial de desarrollo.

Actualmente cuenta con un sistema básico de jugador (`TPlayer`) que incluye:

* ❤️ Vida.
* ❤️ Vida máxima.
* ⚔️ Sistema de daño.
* 💚 Sistema de curación.
* 🛡️ Control de los límites de vida.
* 🧱 Separación de la lógica del jugador mediante una clase independiente.

## 📚 Sobre el proyecto

Este proyecto comenzó como una forma práctica de aprender Delphi mientras desarrollo mi propio videojuego.

La intención no es copiar un juego existente, sino utilizar algunas ideas de los RPG y MMORPG que me gustan como inspiración para crear un proyecto con **mecánicas, sistemas y contenido propios**.

El proyecto se encuentra en desarrollo y su estructura puede cambiar a medida que avance el aprendizaje.
